# PROJECT GOAT ARCHITECTURE

Version: v0.7
Status: Active Development
Architecture Status: Deterministic Scientific Research Platform

---

# 1. Vision

Project GOAT is a deterministic scientific research platform designed to discover, validate, preserve, and deploy statistically robust quantitative trading knowledge.

The platform prioritizes:

- Determinism
- Scientific reproducibility
- Auditability
- Replayability
- Immutable scientific artifacts
- Complete provenance

The objective is not merely to execute trading strategies but to build a scientific operating system capable of producing validated trading intelligence.

---

# 2. Core Design Principles

- Deterministic execution
- Immutable domain models
- Canonical serialization
- Stable identifiers
- Scientific reproducibility
- Replayable workflows
- Append-only history where applicable
- Fail-closed validation
- Explicit provenance
- Backward compatibility with frozen architecture

# 6. Domain Model Philosophy

All domain models are:

- Immutable
- Deterministic
- Canonically serialized
- Hashable
- Replayable
- Auditable

No mutable scientific artifacts.

---

# 7. Persistence Philosophy

Persistence is deterministic.

SQLite repositories are responsible only for persistence.

Repositories never contain scientific reasoning.

---

# 8. Replay Philosophy

Every major subsystem must support deterministic replay.

Replay must reconstruct identical scientific state.

---

# 9. Validation Philosophy

Validation must fail closed.

Reject:

- duplicate IDs
- duplicate hashes
- orphan references
- invalid transitions
- cyclic graphs
- provenance violations
- replay inconsistencies

---
