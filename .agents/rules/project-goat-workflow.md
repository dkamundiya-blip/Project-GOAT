PROJECT GOAT Implementation Workflow

For every implementation step:

1. Inspect previous completed architecture and existing code patterns before implementing new functionality.
2. Create an implementation plan.
3. Immediately begin implementation.
4. Implement every required file.
5. Run dedicated tests.
6. Fix all failures.
7. Run the full regression suite.
8. Fix regressions.
9. Produce the complete Completion & Certification Report.
